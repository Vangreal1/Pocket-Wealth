# Proposed Foreman task contract

`POST /tasks`, JSON; `Authorization: Bearer <WEALTH_TOKEN>` from trusted local Foreman only. `task_id` is caller-generated; mutations with an already-used ID return the original result. `user_id` must come from Foreman's authenticated identity context, never from untrusted chat text. No user may request a different user's records.

Actions and required `data` fields:

- `upsert_profile`: `{ "currency": "USD", "timezone": "America/New_York", "tax_jurisdiction": "US-NY" }`. Do this before writing money records. Currency cannot change once chosen. Currency codes currently support a defined set of two-decimal units only. If migrating v1 data without a profile, review its original currency and pass `confirm_legacy_currency:true` once.
- `upsert_account`: `{ "id": "checking", "name": "Checking", "kind": "cash|investment|property|other_asset|debt", "balance_cents": 120000, "apr_bps": 0, "as_of": "2026-09-26", "source": "manual" }`. Debt balances are positive owed amounts; APR basis points only matter for debts. Same id updates the account.
- `upsert_cashflow`: `{ "id": "pay", "label": "Pay", "kind": "income|expense", "monthly_cents": 300000, "source": "manual" }`. Use normalized monthly amounts; zero is allowed.
- `upsert_goal`: `{ "id": "retirement", "label": "Retirement", "target_cents": 100000000, "target_year": 2045 }`.
- `overview`: no data required; optional `assumptions`: `{ "annual_return_bps": 300, "annual_inflation_bps": 250, "monthly_investment_cents": 0, "years": [1,5,10] }`. Planned investment is limited by entered surplus; uninvested surplus accumulates as cash without a modeled return. Includes `next_12_months` cash outlook and seasonal shortfall alert when enough data exists.
- `upsert_seasonal`: `{ "month": 7, "income_cents": 300000, "expense_cents": 250000 }`. Supply all 12 months to activate seasonal projections. Average monthly values in `overview` are rounded annual averages when active. Monthly investments are limited to positive surplus in each modeled month.
- `add_transactions`: `{ "rows": [{ "posted_on": "2026-09-26", "amount_cents": 1299, "direction": "expense", "category": "groceries", "description": "Market", "account_id": "checking", "source_id": "statement-row-123" }], "dry_run": true }`. Preview by default. An explicit `dry_run:false, approved:true` is required to save; Foreman must derive approval from the user confirmation flow. `source_id` is strongly recommended where repeated same-day transactions can occur.
- `import_csv`: `{ "csv_text": "posted_on,amount_cents,direction,category,description,account_id,source_id\n...", "dry_run": true }`. Same review rule as above; at most 200 rows per batch. Bank statement formats need adapters before this normalized import.
- `upsert_budget`: `{ "category": "groceries", "monthly_limit_cents": 40000 }`.
- `spending_report`: `{ "month": "2026-09" }`. Includes category spending, transfers excluded, budget remaining, and coverage warning.
- `spending_trends`: `{ "months": 12 }`. Month-by-month recorded income/expenses; a month without records means missing coverage, not proven zero spending.
- `upsert_loan_terms`: `{ "account_id": "car_loan", "payment_cents": 40000 }`. Debt account and APR must first exist.
- `loan_analysis`: `{ "account_id": "car_loan", "extra_cents": 10000 }`. Fixed-rate amortization comparison, not a lender statement.
- `debt_plan`: `{ "extra_budget_cents": 10000 }`. Compares avalanche and snowball across all entered positive debts; every debt needs loan terms.
- `compare_loan_quotes`: `{ "principal_cents": 1000000, "quotes": [{ "name": "Credit union", "interest_rate_bps": 700, "term_months": 48, "upfront_fees_cents": 5000 }] }`. Compares manually entered offers; no live lender lookup or eligibility check.
- `upsert_tax_item`: `{ "id": "income-1", "tax_year": 2026, "kind": "employment_income", "amount_cents": 5000000, "note": "manual payslip entry" }`. Kinds: employment_income, benefits, wages, unemployment, self_employment, interest, dividends, capital_gain, withholding, tax_payment, federal_withholding, state_withholding, estimated_payment, potential_deduction, other. Labels organize records; tax treatment depends on the user's jurisdiction.
- `tax_organizer`: `{ "tax_year": 2026 }`. Returns totals only; does not estimate liability, decide deductions or file.
- `retirement_scenario`: `{ "current_age": 35, "retirement_age": 65, "monthly_saving_cents": 50000, "target_monthly_spending_cents": 400000, "other_monthly_income_cents": 0, "annual_return_bps": 300, "annual_inflation_bps": 250 }`. Requires an investment account. Optional `planning_withdrawal_bps` displays an illustrative portfolio draw; it is never assumed by default.
- `paper_open`: `{ "starting_cash_cents": 1000000 }`. Creates a simulated account once per user.
- `paper_order`: `{ "symbol": "ABC", "side": "buy", "quantity": 3, "price_cents": 5000, "fee_cents": 0 }`. Simulated immediate fill at a user supplied price; no brokerage or market data.
- `paper_portfolio`: empty data object. Simulated cash, positions and cost basis; last order prices are stale valuations, not live quotes.
- `market_research_request`: `{ "asset_class": "index", "identifier": "S&P 500", "intent": "overview" }` or `{ "asset_class": "commodity", "identifier": "gold", "intent": "quote" }`. Returns `requires_external_research`; Foreman routes the question to an authorized internet tool. Classes: equity, index, fund, bond, currency, commodity, crypto, economic_series, other. Intents: quote, overview, fundamentals, macro, news. A user-facing result must include its source website link and observation time. This action does not fetch data itself.
- `record_market_observation`: `{ "id": "abc-quote-2026-09-26", "asset_class": "equity", "identifier": "ABC", "metric": "last_price", "value": "123.45", "unit": "USD", "observed_at": "2026-09-26T14:00:00Z", "source_url": "https://example.org/abc", "source_title": "Example source" }`. Restricted to a trusted source connector using the additional source token; the connector must have fetched and checked the source. Wealth validates the structure and timestamp, but does not independently verify the value.
- `market_snapshot`: `{ "asset_class": "equity", "identifier": "ABC" }`. Returns stored observations with their age and source. This is research context, not a live order price.
- `pin_quote_widget`: `{ "id": "home-stock", "symbol": "ABC", "display_name": "Example Co", "asset_class": "equity" }`. Stores one user's home-screen widget preference; returns `pinned_waiting_for_feed` and a proposed same-origin stream path. Supported classes: equity, fund, index, commodity, crypto, currency.
- `list_quote_widgets`: empty data object. Lists only the authenticated user's widget preferences.
- `unpin_quote_widget`: `{ "id": "home-stock" }`. Removes only that user's preference.
- `export_user_data`: empty data object. Returns a JSON snapshot of the authenticated user's current records including task/audit rows; requires a separate data-control gateway token. Handle as a sensitive download; do not print its contents to chat or logs.
- `delete_user_data`: `{ "confirm": "ERASE authenticated-user-id" }`. Requires the same separate gateway token plus a direct user confirmation flow. Deletes only that user's active database rows; no per-user task/audit row is retained after erasure. Exports, backups and filesystem snapshots are separate.

See `ui/QUOTE_WIDGET.md` for the desktop/phone visual component and quote-stream contract. The standalone service does **not** serve a streaming endpoint.

Fields common to every request: `task_id`, `user_id`, `action`. Reusing a task ID with changed content is an error. Return shape: `task_id`, `status`, `result`, `warnings`; errors use `status: error` and an `error` string. All monetary values are integer hundredths of the user's configured two-decimal currency (legacy field suffix `_cents`), rates integer basis points (100 bps = 1%), and scenario values in today's purchasing power. No currency conversion is performed or implied. Assumptions can be varied from -10000 to 20000 bps (return), 0 to 10000 bps (inflation), years 1–50. `source` must be `manual` in this release; no statement or account is implicitly verified. No financial records are returned in audit events.

Foreman should set strict deadlines and should never relay credentials in task descriptions. Distinguish user-entered balances from verified data. A recommendation is a decision aid, not a fiduciary service or an order.

The SQLite database uses `PRAGMA user_version=1` after a transactional migration from the unversioned prototype. A database from a newer Wealth build is refused; upgrade on a copy and keep a recoverable backup. HTTP writes of imported transactions also require `X-Wealth-Approval-Token` in addition to `approved:true`. Export and erase require `X-Wealth-Data-Token`. Those privileges belong only to trusted Pocket/Foreman integration code, never an LLM task payload.
